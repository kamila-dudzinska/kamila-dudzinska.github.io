Mobi – GR Missing automation

One-click reminders to buyers about missing goods receipts, with a statistics report for the administrator.

  • Python
  • pandas
  • Outlook
  • reportlab

Problem

Buyers often forget to post the goods receipt (GR) in SAP Ariba. Without it invoices can’t be paid, and chasing them one by one is repetitive work.

Solution

Mobi reads an SAP Ariba PO export, finds POs in status “ordered” with a delivery date older than 3 days and sends each requestor one e-mail with a table of all their POs.

Result

With one click it saves significant FTE effort and gives administrators a real-time overview of the GR process.

How it works

  1. Reads PO data from a CSV export (SAP Ariba mock data from my generator).
  2. Finds POs in status “ordered” with a delivery date older than 3 days → GR missing.
  3. Each requestor gets ONE e-mail with an HTML table of all their POs (PO, supplier, delivery date, amount + currency).
  4. The administrator gets a PDF report with statistics.
  5. Safe test mode (DRY_RUN = True) opens only 3 e-mail previews; real mode sends the reminders directly.

The report contains

  • KPIs: POs, requestors reminded, POs without GR, e-mails created
  • PO status – all statuses
  • GR missing – aging (days after delivery date)
  • GR missing – blocked value per currency
  • Top 5 requestors with the most POs without GR

What’s next

Connect to an exchange-rate API to convert the blocked value to EUR – to show not only late payment, but also the currency risk of overdue invoices (“loss” or “win” based on the current rate).
